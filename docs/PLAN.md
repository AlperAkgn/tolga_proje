**AFTER/FORM artist portal — kabul edilen uygulama sırası**

Tanıtım sitesi label'in ön yüzü olarak kalır. Label tarafından hesabı verilen sanatçılar giriş yapar, kendi demolarını gönderir ve yalnızca kendi kayıtlarının durumlarını görür. A&R paneli bu sürümün kapsamı dışındadır.

1. Tanıtım sitesine Artist Login bağlantısı — hazır.
2. Sanatçı giriş ekranı — ön yüz önizlemesi hazır.
3. Sanatçı portalı ve demo listesi — ön yüz hazır; 8. adımda örnek kayıtlar kaldırılıp gerçek API bağlantısı eklendi.
4. Demo gönderim formu — dosya seçimi ve form kontrolü ile ön yüz önizlemesi hazır.
5. ASP.NET Core + EF Core + mevcut Docker MySQL temelini kurma — tamamlandı. Mevcut `688c9576f123` konteynerindeki `afterform` veritabanına ilk migration uygulandı; localhost:5000 üzerindeki .NET API gerçek bağlantı için `connected`, şema için `upToDate` yanıtı verdi.
6. ASP.NET Core Identity ile sanatçı hesabı, salt/hash, güvenli giriş, oturum ve çıkış — tamamlandı. İlk girişteki HTTP 500 için CSRF MVC servis kaydı düzeltildi, derleme başarılı ve sunucu yeniden başlatıldı. Kullanıcı kendi hesabıyla giriş yapıp portalın açıldığını doğruladı.
7. Gerçek ses dosyası yükleme, korumalı depolama, dosya kontrolleri ve sahiplik — tamamlandı. 9. adımın normal PowerShell'deki gerçek koşusunda veritabanı/şema readiness kontrolü, üç yapay WAV gönderimi, sahiplik, indirme SHA-256 eşitliği, byte-range ve büyük dosya reddi kontrolleri geçti. Gerçek bir sanatçı şarkısı ve tarayıcı oynatma akışı ayrıca denenmedi.
8. Demo durumları ve ön yüzün gerçek API'ye bağlanması — tamamlandı. Sanatçıya özel liste, durum sayaçları/filtreleri, arama, sayfalama ve ayrıntı sayfası eklendi. Yeni migration yok. Derleme ve sözdizimi kontrolleri başarılı. 9. adım koşusunda gerçek MySQL liste/ayrıntı, arama, durum filtresi, sayfa doğrulaması ve sahiplik API kontrolleri geçti. Tarayıcıdaki görsel/etkileşim akışı bu koşunun kapsamında değildi.
9. Postman ile iki sanatçı hesabının erişim sınırları ve hata senaryoları — tamamlandı. 2 Ekim 2026'da kullanıcı normal PowerShell'de Postman koleksiyonunu Newman ile çalıştırdı: dört grup, 120 istek, 197 kontrol, 0 başarısızlık. Kontrollerin 195'i Postman assertion'ı, ikisi indirilen dosya ve byte-range için gerçek bayt karşılaştırmasıdır. Oturum/sahiplik, dosya/alan doğrulaması, hesap kilidi ve giriş istek sınırı grupları geçti. Önceki 400/413 beklenti farkı düzeltildi; güncel büyük dosya testi açık boyut hatası ve yeni kayıt oluşmamasını da doğruladı. Sonuç `docs/09-last-run.md` dosyasında.
10. Backend'i Docker'a alma ve MySQL/dosya kalıcılığı — tamamlandı. Kullanıcı 2 Ekim 2026'da normal PowerShell'de imajı oluşturup `afterform-backend-1` konteynerini healthy durumda başlattı. `.local/docker/last-start.json` raporu `ready`, MySQL `connected`, şema `upToDate` sonucunu doğruladı. Mevcut `688c9576f123` MySQL konteynerindeki `/var/lib/mysql`, `mysql_data` adlı volume'a bağlı. Demo dosyaları mevcut Windows klasöründen, Linux oturum anahtarları ayrı klasörden bind mount ile bağlandı. Docker'da yükleme sonrası yeniden oluşturma ve güvenlik koleksiyonu ayrıca denenmedi. Rehber: `docs/10-docker-backend.md`; başlatma sonucu: `docs/10-last-start.md`.
11. Canlıya alma aşamasında Azure App Service, MySQL, Blob Storage ve sır yönetimini değerlendirme.

1–10. adımlar tamamlandı. 9. adımın belirtilen API senaryoları ve 10. adımın gerçek Docker başlatma/bağlantı sonuçları raporlar üzerinden doğrulandı. Tarayıcı oynatması, Docker'da yükleme sonrası yeniden oluşturma, üretim HTTPS ayarları ve kapsamlı sızma testi ayrıca yapılmadı. 11. adıma geçilmedi.
